内测规则

同时有效的授权设备最多 10 台，授权有效期 7–90 天，按设备去重；不需要招满才开放。加维护者微信领取授权，并通过微信或内测群反馈。

体验额度由内测用户共用，可能因额度或服务限制暂停，不保证每人的题数或金额。也可以使用自己的 API Key；维护者暂停共享体验额度不影响你的自备 Key，相关费用由服务商另计。

使用前须知：实时转写和默认回答使用 OpenAI 的服务。OpenAI 目前不向中国大陆和香港提供 API，在这些地区需要能稳定访问 OpenAI 的网络环境，否则会连接失败。回答服务可以换成 DeepSeek 等国内能直接访问的服务，但实时转写目前只支持 OpenAI。仍须符合服务商支持地区与账号使用要求。详见常见问题。

扫码领取授权

安装后打开软件，复制授权页上的“设备码”。加维护者微信，备注“面面俱答内测”。通过后把设备码发过来，会发授权文件，并拉你进内测群。收到授权文件后导入即可使用。

只需要发设备码。不要发送 API Key、简历或其他个人资料。

Windows 安装提示

安装时如果出现“Windows 已保护你的电脑”，点“更多信息”，再点“仍要运行”。这是因为安装包还没有购买数字签名，请只从本站下载。

Mac 第一次打开

  1. 双击下载的文件，把“面面俱答”拖进“应用程序”文件夹。
  2. 第一次打开时，系统可能提示“无法验证开发者”。点“完成”，然后打开“系统设置 → 隐私与安全性”，在页面下方点“仍要打开”。测试版还没有做苹果的开发者认证，所以会有这一步。公司或学校统一管理的 Mac 可能不允许这样放行。
  3. 用到麦克风、截图或录制电脑声音时，按系统提示允许权限。改完权限后，退出助手再重新打开。

如果系统提示文件“已损坏”，请不要强行打开，重新从本站下载一次。

Mac 测试版还没验证的部分

我们没有真机，Mac 版是在云端的 Mac 上测试的。安装、授权、导入资料、生成回答都已经测过，下面这些还没在真实电脑上确认：

  • 录制会议软件里对方的声音（腾讯会议、Zoom 等）
  • 软件里的中文朗读
  • macOS 14.2 的电脑，以及多显示器、全屏会议

如果你用的是 Mac，欢迎反馈使用情况。反馈时说明系统版本、芯片和出问题的步骤即可，不要发送 API Key 或真实面试录音。更多限制见已知问题。
