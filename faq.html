常见问题

更详细的操作步骤见使用手册。

我需要准备什么？

一台 Windows 或 Mac 电脑、你的简历和项目资料、目标岗位的要求、授权文件，以及自己的 API Key，或维护者提供的体验额度。只想手动打字提问的话，不需要开麦克风。

在中国大陆能直接用吗？

实时转写和默认的回答服务用的是 OpenAI。OpenAI 目前不向中国大陆和香港提供 API 服务，在这些地区需要你自行解决访问 OpenAI 的网络问题，否则会连接失败。回答服务可以换成 DeepSeek 等国内能直接访问的服务，但实时转写目前只支持 OpenAI；用不了 OpenAI 时，只能手动输入问题让助手作答。能连接网络不代表账号或地区已获支持；请遵守当地法律法规和服务商的使用条款。

API Key 是什么？ChatGPT 会员能用吗？

API Key 是 AI 服务给开发者用的密钥，按用量计费，需要在服务商的开发者后台单独申请并充值。ChatGPT Plus 之类的聊天会员不包含 API 额度，不能直接用。

一场面试大概花多少钱？

取决于你选的模型和题量。软件开始模拟面试前会显示预估费用，实际以服务商账单为准。建议在服务商后台区分支出提醒和强制上限，按实际权限配置。用体验额度不需要自己付费，额度由所有内测用户共用。

“模拟面试”和“AI 预演”有什么区别？

模拟面试是你自己用麦克风回答，答完看参考答案，结束后生成复盘。AI 预演是 AI 按你的资料代答，用来提前看看会被问什么、资料够不够，不代表你本人的表现。

资料里没写的事，助手会帮我编吗？

不会。回答只根据你上传的资料；资料没写的，它会说得比较保守，或者直接说没有相关经历。想让回答更具体，就把项目里实际做过的事写清楚再上传。

面试官话说一半停住了，会不会抢答？

有可能。面试官停顿一两秒以上，助手可能会先按半句话开始回答。这时已经出来的答案会变暗保留，等面试官说完，再按完整的问题重新回答，屏幕不会突然变空。不想被打扰的话，可以关掉“自动作答”，改成手动触发。

真实面试里能用吗？

先确认面试官或公司允许使用辅助工具。助手更适合用来准备和练习：面试前模拟、面试后复盘。

手机能用吗？

手机只能查看，不能操作。电脑和手机在同一个 Wi‑Fi 下时，打开电脑上显示的链接，就能在手机上看到当前的问题和回答。

API Key 保存后，设置里为什么是空的？

为了安全，软件不会把已保存的 Key 显示出来。看到“已配置”就说明保存成功了：留空表示继续用旧的，填新的就会替换。

换电脑或者授权到期了怎么办？

到期后用同一个设备码找我续期，本机资料不会被删除。换电脑或重装系统后设备码可能变化，需要重新领取。

Mac 版为什么是测试版？

Mac 版只在云端的 Mac 上测过，还没在真实电脑上验证过录制会议声音等功能。详细范围见下载页。

遇到问题怎么反馈？

先在设置中点击“反馈问题”，把复制的诊断信息和出问题的步骤粘贴到内测群；需要更多信息时，按群里的建议导出诊断包，确认内容后再分享。请不要发送 API Key、真实面试录音或完整的个人资料。加维护者微信，备注“面试助手内测”。通过后把设备码发过来，会发授权文件，并拉你进内测群。二维码见“获取授权”页。

加入微信内测群

加维护者微信，备注“面试助手内测”。通过后把设备码发过来，会发授权文件，并拉你进内测群。
