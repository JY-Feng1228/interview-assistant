领取授权

每台电脑需要一个授权文件。授权由我手动发放，不用在线激活。

扫码领取授权

安装后打开软件，复制授权页上的“设备码”。加维护者微信，备注“面试助手内测”。通过后把设备码发过来，会发授权文件，并拉你进内测群。收到授权文件后导入即可使用。

只需要发设备码。不要发送 API Key、简历或其他个人资料。

具体步骤

  1. 从下载页安装面试助手。
  2. 打开软件，第一页就是授权页，复制上面的“设备码”。
  3. 加维护者微信，备注“面试助手内测”。通过后把设备码发过来，会发授权文件，并拉你进内测群。
  4. 收到授权文件后，在授权页阅读条款、勾选同意，再点“同意条款并启用”，选择授权文件。

需要知道的

  • 内测期间每次授权 7 天，到期用同一设备码续期。本机资料不会被删除，授权文件不能分给别人用。
  • 换电脑或重装系统后，设备码可能会变，需要重新领取。Windows 和 Mac 的授权不能互用。
  • 授权本身不包含长期 AI 服务。可以使用自己的 API Key，费用由所选服务收取；内测用户也可申请维护者提供的共用体验额度，可能因额度或服务限制暂不可用。

加入微信内测群

加维护者微信，备注“面试助手内测”。通过后把设备码发过来，会发授权文件，并拉你进内测群。
